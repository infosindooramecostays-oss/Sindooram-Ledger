Sindooram ID
Install guide for the property manager

1Open the app

Tap the button below to open it in your phone's browser.

Open Sindooram ID

2Add it to your home screen

iPhone (Safari)
  1. Tap the Share icon (square with an arrow up) at the bottom of the screen.
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add (top right).
Android (Chrome)
  1. Tap the ⋮ menu (top right).
  2. Tap Install app (or "Add to Home screen").
  3. Tap Install.

It'll appear as its own app icon labeled "Sindooram ID" — no browser bars.

3One-time setup inside the app

  1. Open the app → tap Settings at the bottom.
  2. Under "Your name," type your name — this tags every document you upload.
  3. Paste this into "Apps Script Web App URL," then tap Save & connect:
https://script.google.com/macros/s/AKfycbym-eMNh9Gk5XipPzebTE0rGeYKmav0Fi3PLKO21mS8EKAhVWdD_1WidNMg8P1n6eny/exec

4Uploading documents

  1. Open the app → Bookings tab shows current confirmed bookings.
  2. Tap a booking — guest name, booking number, check-in date, and any remarks fill in automatically.
  3. Add a note in Additional comments if needed (optional).
  4. Tap Take Photo for the camera, Choose Photos to pick several photos at once, or Choose Document for a PDF/Word file. Add as many as you need. Tap View on any of them to double-check it's right.
  5. Tap Submit, then confirm — all files upload together.
  6. Once uploaded, they'll show under Documents on file with a count and a View link for each — this stays visible even if you close the app and come back later.

Files are saved automatically. The app will ask "are you sure?" before removing a file or submitting, so mistakes are hard to make.

# Sindooram Ledger

Shared expense, income, and booking tracker for the villa. A Google Sheet is
the database; this page is the mobile-friendly interface everyone uses.

**Live app:** https://infosindooramecostays-oss.github.io/Sindooram-Ledger/

See [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md) for how it all fits together,
how to connect a device, and how to deploy changes.
